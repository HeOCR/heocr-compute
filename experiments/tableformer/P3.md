## Recipe and weight gate

- Start at the existing stock ACCURATE model and ABI. Fix seed 32, AdamW LR `1e-5` with no weight decay, one crop per step and three epochs. Cap at 768 updates. Clip the gradient norm at 1. Keep the image encoder, encoder-side input filter and tag encoder frozen. Fixed inference-mode layers remain deterministic during backpropagation.
- Update embeddings, every causal structure decoder block, the OTSL classifier and the full bbox decoder. Combine next-token cross entropy, twice the normalized Smooth L1 box loss and a 0.1-weight KL term for the bbox class outputs against a frozen stock teacher. The teacher preserves the upstream box class semantics while the box coordinates learn from projected gold. Match the stock decoder's emission positions, including its horizontal-span merge endpoints.
- Publish one terminal safetensors file with the training receipt and logs. Reload the saved tensors and compare each to the pinned stock checkpoint. Every required trainable group, including every structure block and both bbox output heads, must have a nonzero change. The audit checks shapes, dtypes, nonfinite deltas, counts of changed elements and maximum absolute deltas. All frozen tensors and buffers must match byte-for-byte. A head-only result fails the audit.
